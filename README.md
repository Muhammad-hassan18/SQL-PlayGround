# 🗺️ SQL Learning Roadmap

## 🟢 01 — SQL Fundamentals

Building the foundation required to work confidently with relational databases.

* SQL & Relational Databases
* Database & Table Structure
* `SELECT`
* `FROM`
* `DISTINCT`
* `TOP`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* `HAVING`

---

## 🔵 02 — Database & Data Manipulation

Learning how databases and their data are created and managed.

### DDL

* `CREATE`
* `ALTER`
* `DROP`

### DML

* `INSERT`
* `UPDATE`
* `DELETE`

Understanding tables, columns, data types, and modifying data safely.

---

## 🟡 03 — Filtering & Data Analysis

Learning to extract meaningful information from datasets.

* Comparison Operators
* Logical Operators
* `AND`, `OR`, `NOT`
* `IN`
* `BETWEEN`
* `LIKE`
* `IS NULL`
* Conditional filtering
* Aggregations
* Group-based analysis

---

## 🟠 04 — SQL Joins

One of the most important SQL skills for real-world data analysis.

* `INNER JOIN`
* `LEFT JOIN`
* `RIGHT JOIN`
* `FULL OUTER JOIN`
* Self Join
* Multiple-table joins
* Advanced join scenarios

> **Goal:** Combine data from multiple related tables accurately and efficiently.

---

## 🟣 05 — SQL Functions

Learning how to transform and manipulate data.

### String Functions

* Text cleaning
* Concatenation
* Extraction
* Formatting

### Numeric Functions

* Rounding
* Mathematical calculations
* Numeric transformations

### Date & Time Functions

* Date extraction
* Date calculations
* Date filtering
* Time-based analysis

### NULL Handling

* Handling missing values
* Replacing NULL values
* NULL-aware calculations

---

## 🔷 06 — Conditional & Aggregate Analysis

Using SQL to answer business questions and generate analytical insights.

* `CASE`
* `SUM`
* `COUNT`
* `AVG`
* `MIN`
* `MAX`
* Conditional aggregation
* Group-level analysis

---

## 🔥 07 — Window Functions

Developing advanced analytical SQL skills without collapsing data into groups.

### Window Aggregations

* Running totals
* Moving calculations
* Partition-based analysis

### Ranking

* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`

### Window Value Functions

* `LAG()`
* `LEAD()`
* Previous/next record analysis

> **Focus:** Business analytics, trends, rankings, comparisons, and time-based analysis.

---

## 🚀 08 — Advanced SQL

Moving from basic querying to professional SQL development.

* Subqueries
* Correlated Subqueries
* Common Table Expressions (CTEs)
* Views
* Temporary Tables
* CTAS
* Set Operators
* Advanced query techniques

---

## ⚡ 09 — SQL Performance & Optimization

Understanding how SQL queries actually execute and how to make them faster.

* Indexes
* Execution Plans
* Query Optimization
* Index Optimization
* Performance Bottlenecks
* Efficient Filtering & Joins
* Query Performance Best Practices

> **Goal:** Write SQL that is not only correct, but also **efficient and scalable.**

---

## 🗄️ 10 — Database Programming

Understanding SQL features used in production database environments.

* Stored Procedures
* Triggers
* Database Automation
* Reusable SQL Logic
